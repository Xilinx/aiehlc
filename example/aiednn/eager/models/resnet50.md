# resnet50 in aiednn eager mode

torchvision ResNet-50 (ImageNet weights, `weights="DEFAULT"`), an image classifier with bottleneck blocks; input `[1, 3, 224, 224]`, a real ImageNet image (`zoo.image_input()`). Quantized to int8 and lowered through the aiednn MLIR pipeline, it becomes **58 aiednn primitives** in the generated C app. The eager plan of the primary build (`resnet50_int8_mlir_8x4_warm_eager`, mesh 8x4, warm) makes **25 kernel instances** that serve **58 of those layers**; on the board `aiednn_stats` counts **512 AIE launches** in the timed run. Each instance is one shape-specialized template instantiation, loaded right before the layer it serves runs.

## Run it

```bash
python example/aiednn/eager/models/run.py --model resnet50                # x86 emulation, 4x4
python example/aiednn/eager/models/run.py --model resnet50 --show         # + plan and instance code
python example/aiednn/eager/models/run.py --model resnet50 --mesh 8x4 --target vek280 --board galerina13 \
    --vitis-settings <.../Vitis/settings64.sh>
# the same through the model runner (builds worklocal/aiednn/models/resnet50_int8_mlir_8x4[_warm]_eager):
python example/aiednn/models/run_models.py --models resnet50 --modes int8 --app vek280 --board galerina13 \
    --eager --eager-mesh 8x4 --mlir [--tag warm]
```

`--tag warm` only names the build directory; the warm launch is in the current code.

## 1. The PyTorch model

A torchvision model; [`zoo.py`](../../../../example/aiednn/models/zoo.py) `build()` constructs it as:

```python
m = getattr(tvm, name)(weights="DEFAULT" if pretrained else None).eval()
```

i.e. `torchvision.models.resnet50(weights="DEFAULT").eval()`.

## 2. aiednn primitives (generated C app)

[`resnet50_int8_mlir_8x4_warm_eager/resnet50_app.cc`](../../../../worklocal/aiednn/models/resnet50_int8_mlir_8x4_warm_eager/resnet50_app.cc), first line:

Op 1 (`conv1`), the first int8 `aiednn_convolution_forward_create_attr` block, verbatim up to its execute (long constant arrays shortened to their first values):

```c
    {
        g_op_name[1] = "conv1";
        static const aiednn_memory_desc_t m0 = {4, {1, 3, 224, 224}, aiednn_s8};
        static const aiednn_memory_desc_t m1 = {4, {64, 3, 7, 7}, aiednn_s8};
        static const aiednn_memory_desc_t m2 = {1, {64}, aiednn_f32};
        static const aiednn_memory_desc_t m3 = {4, {1, 64, 112, 112}, aiednn_s8};
        static const aiednn_conv_params_t c4 = {{2, 2}, {3, 3}, {3, 3}, {0, 0}, 1};
        static const float s5[] = {0.0004266165487933904f, 0.00015548388182651252f, 0.0001165355060948059f, /* ... 64 values */};
        static const aiednn_attr_t c5 = {64, s5, 0.30827799439430237f, 0, 1, {{aiednn_post_op_eltwise, aiednn_eltwise_relu, 0.0f, 0.0f, {}}}};
        if (force_ref(1)) aiednn_set_impl_filter("ref:"); // dnn_build: not worth a switch
        st = aiednn_convolution_forward_create_attr(&p, &m0, &m1, &m2, &m3, &c4, &c5);
        if (force_ref(1)) aiednn_set_impl_filter(nullptr);
        if (st != aiednn_success) return fail(1, "create", st);
        aiednn_primitive_set_constant_weights(p, 1); // model weights: packed blocks cached
        snprintf(g_impl_buf[1], 64, "%s", aiednn_primitive_impl_info(p));
        g_op_impl[1] = g_impl_buf[1];
        const aiednn_exec_arg_t a[] = {{AIEDNN_ARG_SRC, P1}, {AIEDNN_ARG_WEIGHTS, P2}, {AIEDNN_ARG_DST, P4}, {AIEDNN_ARG_BIAS, P3}};
        aiednn_op_begin(1); // per-op usage; a multi-megakernel build switches here
        const uint64_t t0 = now_ticks();
        st = aiednn_primitive_execute_args(p, 4, a);
        g_op_ticks[1] += now_ticks() - t0;
        aiednn_primitive_destroy(p);
        if (st != aiednn_success) return fail(1, "execute", st);
```

In the app this is followed by an `#if VERIFY_GEMM` block that re-runs the layer with the `ref:` implementation and `memcmp`s the result (the `gemm_checked` / `gemm_bad` counters).

The aiednn MLIR after the pass pipeline, [`ir/resnet50.opt.mlir`](../../../../worklocal/aiednn/models/resnet50_int8_mlir_8x4_warm_eager/ir/resnet50.opt.mlir), holds: conv 53, reorder 2, matmul 1, pooling 1, reduction 1, view 1 (+ 108 `aiednn.const`).

## 5. The template

### [`quant`](../../../../src/aietensorop/eager/quant_eager_kernel.cc)

```cpp
// M a multiple of HW_ROWS * TM, N of 16, N / 4 <= TM (W's block {N/4, N} must not exceed A's {TM, N})
template <int M, int N, int U8, int TM = 16>
__global__ void quant(aie::port<input_window_int8 *, aie::IFM, aie::shape<M, 4 * N>> a,
                      aie::port<input_window_int8 *, aie::WEIGHTS, aie::shape<N, 4 * N>> w,
                      aie::port<output_window_int8 *, aie::OFM, aie::shape<M, N>> c) {
```

### [`gemm_q`](../../../../src/aietensorop/eager/gemm_q_eager_kernel.cc)

```cpp
// M a multiple of HW_ROWS * TM, N of 4, K of TK, TK of 4 and >= 32 (the Q chunk holds 8 int32 per channel), TN * 8
// int32 of Q fit the core's stack
template <int M, int N, int K, int TK = 64, int TM = 16>
__global__ void gemm_q(aie::port<input_window_int8 *, aie::IFM, aie::shape<M, K + TK>> a,
                       aie::port<input_window_int8 *, aie::WEIGHTS, aie::shape<N, K + TK>> w,
                       aie::port<output_window_int8 *, aie::OFM, aie::shape<M, N>> c) {
```

### [`pool`](../../../../src/aietensorop/eager/pool_eager_kernel.cc)

```cpp
// MW a multiple of 4 HW_ROWS * TR (every mesh row gets whole TR-row tiles), KK of 4 (taps + the divisor word)

__global__ void pool(aie::port<input_window_int8 *, aie::IFM, aie::shape<MW / 4, 4 * KK>> x,
                     aie::port<input_window_int8 *, aie::WEIGHTS, aie::shape<16, 4 * KK>> z,
                     aie::port<output_window_int8 *, aie::OFM, aie::shape<MW / 4, 16>> y) {
```
