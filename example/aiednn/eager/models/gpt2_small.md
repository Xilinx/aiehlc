# gpt2_small in aiednn eager mode

GPT-2 small (12 x 768, 12 heads), pre-norm, causal attention, the prefill pass on [1, S, 768]; input `[1, 128, 768]` (random embeddings; random weights). Quantized to int8 and lowered through the aiednn MLIR pipeline, it becomes **109 aiednn primitives** in the generated C app. The eager plan of the primary build (`gpt2_small_int8_mlir_8x4_warm_eager`, mesh 8x4, warm) makes **4 kernel instances** that serve **97 of those layers**; on the board `aiednn_stats` counts **1753 AIE launches** in the timed run. Each instance is one shape-specialized template instantiation, loaded right before the layer it serves runs.

## Run it

```bash
python example/aiednn/eager/models/run.py --model gpt2_small                # x86 emulation, 4x4
python example/aiednn/eager/models/run.py --model gpt2_small --show         # + plan and instance code
python example/aiednn/eager/models/run.py --model gpt2_small --mesh 8x4 --target vek280 --board galerina13 \
    --vitis-settings <.../Vitis/settings64.sh>
# the same through the model runner (builds worklocal/aiednn/models/gpt2_small_int8_mlir_8x4[_warm]_eager):
python example/aiednn/models/run_models.py --models gpt2_small --modes int8 --app vek280 --board galerina13 \
    --eager --eager-mesh 8x4 --mlir [--tag warm]
```

`--tag warm` only names the build directory; the warm launch is in the current code.

## 1. The PyTorch model

From [`example/aiednn/models/zoo.py`](../../../../example/aiednn/models/zoo.py) (`GPT2Block`, `GPT2Small`):

```python
class GPT2Block(nn.Module):
    def __init__(self, d, heads):
        super().__init__()
        self.h = heads
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.qkv, self.proj = nn.Linear(d, 3 * d), nn.Linear(d, d)
        self.fc, self.out = nn.Linear(d, 4 * d), nn.Linear(4 * d, d)

    def forward(self, x):
        b, s, d = x.shape
        q, k, v = self.qkv(self.ln1(x)).split(d, dim=2)
        sh = lambda t: t.reshape(b, s, self.h, d // self.h).permute(0, 2, 1, 3)
        a = F.scaled_dot_product_attention(sh(q), sh(k), sh(v), is_causal=True)
        x = x + self.proj(a.permute(0, 2, 1, 3).reshape(b, s, d))
        return x + self.out(F.gelu(self.fc(self.ln2(x)), approximate="tanh"))


class GPT2Small(nn.Module):
    """GPT-2 small (12 x 768, 12 heads), pre-norm, causal attention, the prefill pass on [1, S, 768]"""

    def __init__(self, layers=12, d=768, heads=12):
        super().__init__()
        self.blocks = nn.ModuleList([GPT2Block(d, heads) for _ in range(layers)])
        self.ln_f = nn.LayerNorm(d)

    def forward(self, x):
        for b in self.blocks:
            x = b(x)
        return self.ln_f(x)
```

Model and input shape, from `zoo.BENCH`: `"gpt2_small": (GPT2Small, (1, 128, 768))`
