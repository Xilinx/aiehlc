# bert_base in aiednn eager mode

BERT-base encoder (12 x 768, 12 heads, FFN 3072) on [1, S, 768] embeddings + a padding mask; input `[1, 128, 768]` (random embeddings; random weights). Quantized to int8 and lowered through the aiednn MLIR pipeline, it becomes **111 aiednn primitives** in the generated C app. The eager plan of the primary build (`bert_base_int8_mlir_8x4_eager`, mesh 8x4, baseline) makes **4 kernel instances** that serve **98 of those layers**; on the board `aiednn_stats` counts **1765 AIE launches** in the timed run. Each instance is one shape-specialized template instantiation, loaded right before the layer it serves runs.

## Run it

```bash
python example/aiednn/eager/models/run.py --model bert_base                # x86 emulation, 4x4
python example/aiednn/eager/models/run.py --model bert_base --show         # + plan and instance code
python example/aiednn/eager/models/run.py --model bert_base --mesh 8x4 --target vek280 --board galerina13 \
    --vitis-settings <.../Vitis/settings64.sh>
# the same through the model runner (builds worklocal/aiednn/models/bert_base_int8_mlir_8x4[_warm]_eager):
python example/aiednn/models/run_models.py --models bert_base --modes int8 --app vek280 --board galerina13 \
    --eager --eager-mesh 8x4 --mlir [--tag warm]
```

`--tag warm` only names the build directory; the warm launch is in the current code.

## 1. The PyTorch model

From [`example/aiednn/models/zoo.py`](../../../../example/aiednn/models/zoo.py) (`BertLayer`, `BertBase`):

```python
class BertLayer(nn.Module):
    """post-norm encoder layer: fused-QKV-free self attention with an additive mask, GELU (erf) MLP"""

    def __init__(self, d, heads, ff):
        super().__init__()
        self.h = heads
        self.q, self.k, self.v, self.o = (nn.Linear(d, d) for _ in range(4))
        self.n1, self.n2 = nn.LayerNorm(d, eps=1e-12), nn.LayerNorm(d, eps=1e-12)
        self.f1, self.f2 = nn.Linear(d, ff), nn.Linear(ff, d)

    def split(self, t):
        b, s, d = t.shape
        return t.reshape(b, s, self.h, d // self.h).permute(0, 2, 1, 3)

    def forward(self, x, mask):
        b, s, d = x.shape
        a = F.scaled_dot_product_attention(self.split(self.q(x)), self.split(self.k(x)), self.split(self.v(x)),
                                           attn_mask=mask)
        x = self.n1(x + self.o(a.permute(0, 2, 1, 3).reshape(b, s, d)))
        return self.n2(x + self.f2(F.gelu(self.f1(x))))


class BertBase(nn.Module):
    """BERT-base encoder (12 x 768, 12 heads, FFN 3072) on [1, S, 768] embeddings + a padding mask"""

    def __init__(self, layers=12, d=768, heads=12, ff=3072, seq=128, valid=100):
        super().__init__()
        self.emb_norm = nn.LayerNorm(d, eps=1e-12)
        self.layers = nn.ModuleList([BertLayer(d, heads, ff) for _ in range(layers)])
        m = torch.zeros(1, 1, 1, seq)
        m[..., valid:] = -10000.0                      # the last tokens are padding
        self.register_buffer("mask", m)
        self.pool = nn.Linear(d, d)

    def forward(self, x):
        x = self.emb_norm(x)
        for layer in self.layers:
            x = layer(x, self.mask)
        return torch.tanh(self.pool(x[:, 0]))
```

Model and input shape, from `zoo.BENCH`: `"bert_base": (BertBase, (1, 128, 768))`
