# mobilenet_v2 in aiednn eager mode

torchvision MobileNetV2 (ImageNet weights, `weights="DEFAULT"`), an image classifier built from inverted residual blocks with depthwise convolutions; input `[1, 3, 224, 224]`, a real ImageNet image (`zoo.image_input()`). Quantized to int8 and lowered through the aiednn MLIR pipeline, it becomes **56 aiednn primitives** in the generated C app. The eager plan of the primary build (`mobilenet_v2_int8_mlir_8x4_warm_eager`, mesh 8x4, warm) makes **24 kernel instances** that serve **56 of those layers**; on the board `aiednn_stats` counts **351 AIE launches** in the timed run. Each instance is one shape-specialized template instantiation, loaded right before the layer it serves runs.

## Run it

```bash
python example/aiednn/eager/models/run.py --model mobilenet_v2                # x86 emulation, 4x4
python example/aiednn/eager/models/run.py --model mobilenet_v2 --show         # + plan and instance code
python example/aiednn/eager/models/run.py --model mobilenet_v2 --mesh 8x4 --target vek280 --board galerina13 \
    --vitis-settings <.../Vitis/settings64.sh>
# the same through the model runner (builds worklocal/aiednn/models/mobilenet_v2_int8_mlir_8x4[_warm]_eager):
python example/aiednn/models/run_models.py --models mobilenet_v2 --modes int8 --app vek280 --board galerina13 \
    --eager --eager-mesh 8x4 --mlir [--tag warm]
```

`--tag warm` only names the build directory; the warm launch is in the current code.

## 1. The PyTorch model

A torchvision model; [`zoo.py`](../../../../example/aiednn/models/zoo.py) `build()` constructs it as:

```python
m = getattr(tvm, name)(weights="DEFAULT" if pretrained else None).eval()
```

i.e. `torchvision.models.mobilenet_v2(weights="DEFAULT").eval()`.

## 2. aiednn primitives (generated C app)

[`mobilenet_v2_int8_mlir_8x4_warm_eager/mobilenet_v2_app.cc`](../../../../worklocal/aiednn/models/mobilenet_v2_int8_mlir_8x4_warm_eager/mobilenet_v2_app.cc), first line:

```c
/* Generated by aiegraph/dnn_torch.py: mobilenet_v2 [int8]: 56 primitives (convolution_attr 52, reorder 2, reduction 1, matmul_attr 1); constants 3.5 MB */
```

| create function | primitives |
|---|---:|
| `aiednn_convolution_forward_create_attr` | 52 |
| `aiednn_reorder_create` | 2 |
| `aiednn_matmul_forward_create_attr` | 1 |
| `aiednn_reduction_create` | 1 |
| **total** | **56** |

Op 1 (`features_0_0`), the first int8 `aiednn_convolution_forward_create_attr` block, verbatim up to its execute (long constant arrays shortened to their first values):

```c
    {
        g_op_name[1] = "features_0_0";
        static const aiednn_memory_desc_t m0 = {4, {1, 3, 224, 224}, aiednn_s8};
        static const aiednn_memory_desc_t m1 = {4, {32, 3, 3, 3}, aiednn_s8};
        static const aiednn_memory_desc_t m2 = {1, {32}, aiednn_f32};
        static const aiednn_memory_desc_t m3 = {4, {1, 32, 112, 112}, aiednn_s8};
        static const aiednn_conv_params_t c4 = {{2, 2}, {1, 1}, {1, 1}, {0, 0}, 1};
        static const float s5[] = {5.0595404900377616e-05f, 0.00036847146111540496f, 0.0002169389190385118f, /* ... 32 values */};
        static const aiednn_attr_t c5 = {32, s5, 0.04724409431219101f, 0, 1, {{aiednn_post_op_eltwise, aiednn_eltwise_clip, 0.0f, 6.0f, {}}}};
        if (force_ref(1)) aiednn_set_impl_filter("ref:"); // dnn_build: not worth a switch
        st = aiednn_convolution_forward_create_attr(&p, &m0, &m1, &m2, &m3, &c4, &c5);
        if (force_ref(1)) aiednn_set_impl_filter(nullptr);
        if (st != aiednn_success) return fail(1, "create", st);
        aiednn_primitive_set_constant_weights(p, 1); // model weights: packed blocks cached
        snprintf(g_impl_buf[1], 64, "%s", aiednn_primitive_impl_info(p));
        g_op_impl[1] = g_impl_buf[1];
        const aiednn_exec_arg_t a[] = {{AIEDNN_ARG_SRC, P1}, {AIEDNN_ARG_WEIGHTS, P2}, {AIEDNN_ARG_DST, P4}, {AIEDNN_ARG_BIAS, P3}};
        aiednn_op_begin(1); // per-op usage; a multi-megakernel build switches here
        const uint64_t t0 = now_ticks();
        st = aiednn_primitive_execute_args(p, 4, a);
        g_op_ticks[1] += now_ticks() - t0;
        aiednn_primitive_destroy(p);
        if (st != aiednn_success) return fail(1, "execute", st);
```

In the app this is followed by an `#if VERIFY_GEMM` block that re-runs the layer with the `ref:` implementation and `memcmp`s the result (the `gemm_checked` / `gemm_bad` counters).

The aiednn MLIR after the pass pipeline, [`ir/mobilenet_v2.opt.mlir`](../../../../worklocal/aiednn/models/mobilenet_v2_int8_mlir_8x4_warm_eager/ir/mobilenet_v2.opt.mlir), holds: conv 52, reorder 2, matmul 1, reduction 1, view 1 (+ 106 `aiednn.const`).
