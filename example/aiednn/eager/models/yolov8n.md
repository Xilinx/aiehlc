# yolov8n in aiednn eager mode

ultralytics YOLOv8n, an object detector, with the released COCO weights (`yolov8n.pt`, the head in export mode: one output tensor, no NMS); input `[1, 3, 320, 320]` (ultralytics' bus.jpg resized to 320 x 320). Quantized to int8 and lowered through the aiednn MLIR pipeline, it becomes **150 aiednn primitives** in the generated C app. The eager plan of the primary build (`yolov8n_int8_mlir_8x4_eager`, mesh 8x4, baseline) makes **40 kernel instances** that serve **103 of those layers**; on the board `aiednn_stats` counts **465 AIE launches** in the timed run. Each instance is one shape-specialized template instantiation, loaded right before the layer it serves runs.

Layers the planner refused (from `eager_instances.json`):

- `l__self___model_22_dfl_conv`: N = 1: not a multiple of 4 (each mesh column owns N / 4 columns)

## Run it

```bash
python example/aiednn/eager/models/run.py --model yolov8n                # x86 emulation, 4x4
python example/aiednn/eager/models/run.py --model yolov8n --show         # + plan and instance code
python example/aiednn/eager/models/run.py --model yolov8n --mesh 8x4 --target vek280 --board galerina13 \
    --vitis-settings <.../Vitis/settings64.sh>
# the same through the model runner (builds worklocal/aiednn/models/yolov8n_int8_mlir_8x4[_warm]_eager):
python example/aiednn/models/run_models.py --models yolov8n --modes int8 --app vek280 --board galerina13 \
    --eager --eager-mesh 8x4 --mlir [--tag warm]
```

`--tag warm` only names the build directory; the warm launch is in the current code.

## 1. The PyTorch model

From [`example/aiednn/models/zoo.py`](../../../../example/aiednn/models/zoo.py) (`_yolov8n`, `_c2f_forward`):

```python
def _yolov8n():
    """The released COCO weights. DetectionModel("yolov8n.yaml") alone has random weights whose
    activations shrink layer by layer (int8 scales down to 3e-12): every output saturates, so
    PyTorch, ref: and the AIE agree on a degenerate model and its timings mean nothing."""
    import ultralytics.nn.tasks  # noqa: F401 -- ultralytics (no-deps install + opencv-python-headless): unpickles the model
    if not YOLOV8N_PT.is_file():
        import urllib.request
        YOLOV8N_PT.parent.mkdir(parents=True, exist_ok=True)
        try:
            urllib.request.urlretrieve(YOLOV8N_URL, YOLOV8N_PT)
        except OSError as e:
            raise SystemExit(f"yolov8n: cannot download {YOLOV8N_URL} ({e}); put the file at {YOLOV8N_PT}")
    m = torch.load(YOLOV8N_PT, map_location="cpu", weights_only=False)["model"].float()
    m.model[-1].export = True                          # the head returns one tensor (no NMS inside)
    from ultralytics.nn.modules.block import C2f
    for mod in m.modules():
        if isinstance(mod, C2f):
            mod.forward = types.MethodType(_c2f_forward, mod)
    return m


def _c2f_forward(self, x):
    """C2f.forward as a plain loop. Upstream's y.extend(m(y[-1]) for m in self.m) feeds each
    bottleneck the previous one's output; torch 2.4's Dynamo evaluates that generator against the
    list as it was, so a traced C2f with n >= 2 (yolov8n layers 4 and 6) computes something else
    (bus score 0.72 vs 0.92 eager) -- and both the direct path's fallback tracer and torch.compile use Dynamo."""
    y = list(self.cv1(x).chunk(2, 1))
    for m in self.m:
        y.append(m(y[-1]))
    return self.cv2(torch.cat(y, 1))
```

Model and input shape, from `zoo.BENCH`: `"yolov8n": (_yolov8n, (1, 3, 320, 320))`
