# Run ResNet18 on the AIE with aiegraph: classifying real images

This tutorial deploys **ResNet18** (ImageNet, 1×3×224×224 → 1000 logits) to a palmyra board (A78 APU + AIE2PS): the A78 runs the whole network as C code generated by TVM, **all 20 Conv layers and the 1 Gemm** run on the AIE through aiegraph's group offload, and the board then classifies real images and is compared with onnxruntime.

It uses the same aiegraph as [tiny-SD UNet](tiny-sdm-unet.md) and [YOLOv26](yolov26.md). The difference is that a CNN needs no hand-written partition: `aiegraph.cnn.offload_all()` matches every Conv / weighted Gemm into a group automatically and places it on a bf16 `gemm_kacc` instance. The user writes only `build_resnet18.py` (listed in full in section 3), and it contains no C text.

Every number was measured on palmyra213 (10.23.224.213); see [Measured results](#measured-results).

---

## 0. How it works

```
resnet18_fp32_op17.onnx ─► ag.load ─► m.convert(target="a78") ─► TVM C: graph_driver.c (layer by layer on the A78)
                                         │
                       aiegraph.cnn.offload_all(emod, model, out)
                         │  plan_layers: each Conv / Gemm ─► an (N, K, M) matmul ─► pick a gemm_kacc instance (10 in total)
                         │  small layers with K ≤ 128 are zero-padded onto a larger-K instance (merge_small_k)
                         │  kernel_source: src/aiednn/gemm + src/aiednn/conv2d templates ─► one aiek source file
                         │  emod.offload_group(...): 20 aiednn_conv + 1 aiednn_dense call sites
                                         ▼
                emod.build(target="a78", runtime_io=[("input", ...)]) ─► main.elf (123 MB, input in the .aiehlc_io section)

On the board: aiehlc_elfio.py patch swaps the input ─► apppaltest.py --netload ─► output dump (1000 fp32 logits) ─► compare with onnxruntime
```

- **How a conv gets onto the AIE:** im2col on the A78 turns the conv into a matrix multiply ([`src/aiednn/conv2d/kacc_gemm_pad_host.cc`](../../src/aiednn/conv2d/kacc_gemm_pad_host.cc), zero-padded to the instance size), and the AIE runs `gemm_kacc` ([`src/aiednn/gemm/gemm_kacc_kernel.cc`](../../src/aiednn/gemm/gemm_kacc_kernel.cc)): bf16 multiplies, fp32 accumulation, K accumulated inside the core.
- **Fully connected layer:** the final Gemm (512 → 1000) also goes through gemm_kacc (the `aiednn_dense` call site).
- **147 AIE launches per inference**, with warm launch (kernels loaded once) + control-packet AOT + KCO ([`src/aiednn/gemm/ctrlpkt_aot_pragmas.h`](../../src/aiednn/gemm/ctrlpkt_aot_pragmas.h), [`ctrlpkt_kco_pragma.h`](../../src/aiednn/gemm/ctrlpkt_kco_pragma.h)).

aiegraph modules used: [`aiegraph/cnn.py`](../../src/aiegraph/cnn.py) (CNN group offload) and [`aiegraph/boardmain.py`](../../src/aiegraph/boardmain.py) (board main, input/reference headers, driver glue). For general aiegraph usage see the [aiegraph tutorial](../../doc/tutorial_aiegraph.md).

## 2. Prepare a real image

Preprocessing matches torchvision's ImageNet evaluation: resize the short side to 256 (bilinear), center-crop 224, /255, subtract the mean and divide by the std, NCHW fp32. This uses a tench (class 0) from the imagenette validation set:

```bash
IMG=/scratch/staff/huaj/modelzoo/data/imagenette_dl/imagenette2-320/val/n01440764/n01440764_10040.JPEG
$PY - "$IMG" $WORK/img0.bin $ONNX <<'PY'
import sys, numpy as np, onnxruntime as ort
from PIL import Image
img, out, onnx = sys.argv[1:]
im = Image.open(img).convert("RGB"); w, h = im.size; s = 256 / min(w, h)
im = im.resize((max(256, round(w * s)), max(256, round(h * s))), Image.BILINEAR); w, h = im.size
l, t = (w - 224) // 2, (h - 224) // 2
mean, std = np.array([0.485, 0.456, 0.406], np.float32), np.array([0.229, 0.224, 0.225], np.float32)
a = (np.asarray(im.crop((l, t, l + 224, t + 224)), np.float32) / 255.0 - mean) / std
x = np.ascontiguousarray(a.transpose(2, 0, 1)[None], np.float32); x.tofile(out)
sess = ort.InferenceSession(onnx, providers=["CPUExecutionProvider"])
ref = sess.run(None, {sess.get_inputs()[0].name: x})[0].reshape(-1)
ref.astype("<f4").tofile(out.replace(".bin", "_ort.bin"))
print("ORT top-5", np.argsort(-ref)[:5].tolist())
PY
```

This produces `$WORK/img0.bin` (602112 B, the board's input) and `$WORK/img0_ort.bin` (onnxruntime's 1000 fp32 logits, the reference for the board's result).

## 3. All of the user-side source: build_resnet18.py

This is the full text of [`example/aiegraph/resnet18/build_resnet18.py`](../../example/aiegraph/resnet18/build_resnet18.py). It only declares the model's input, its reference output and the options; the offload is one line, `cnn.offload_all(...)`.

```python
#!/usr/bin/env python3
"""ResNet18 (ONNX, 1x3x224x224 -> 1000 logits) -> aiegraph -> A78 main.elf, every Conv and the Gemm on the AIE.

  $PY build_resnet18.py --onnx resnet18_fp32_op17.onnx --out <dir> [--input in.bin] [--ctrlpkt aot-kco]

This file only declares the model's input, its reference and the options. aiegraph does the rest:
  aiegraph.cnn        every Conv / weighted Gemm -> one aiegraph group on a bf16 gemm_kacc instance
                      (templates in src/aiednn/{gemm,conv2d}), archive on a carrier layer;
  aiegraph.boardmain  board main.c, inputs header, reference header, driver glue;
  emod.build          main.elf with the input in the .aiehlc_io section (patch it with aiehlc_elfio.py).
The build's own input is --input (raw fp32 NCHW) or a seeded N(0,1) tensor; its onnxruntime output is the
reference the board compares against when it runs that input. The build log prints
'OFFLOAD resnet18 conv=n/N gemm=m/M AIE_MAC_SHARE=x%'.
"""
import argparse
import os
import shutil
import sys
import zlib
from pathlib import Path

import numpy as np

HERE = Path(__file__).resolve().parent
sys.path[:0] = [str(HERE.parents[2] / "src")]   # this checkout's aiegraph / aiednn


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__.split("\n")[0])
    ap.add_argument("--onnx", required=True, type=Path)
    ap.add_argument("--out", required=True, type=Path)
    ap.add_argument("--input", type=Path, default=None, help="raw fp32 1x3x224x224 (default: seeded N(0,1))")
    ap.add_argument("--ctrlpkt", choices=("off", "aot", "aot-kco"), default="aot-kco", help="control-packet plan")
    ap.add_argument("--launch-opt", choices=("cold", "warm"), default="warm", help="warm: kernels loaded once")
    ap.add_argument("--verbose", action="store_true")
    a = ap.parse_args(argv)
    log = lambda msg: print(f"[build_resnet18] {msg}", flush=True)
    import onnx
    import onnxruntime as ort
    import aiegraph as ag
    from aiegraph import boardmain as bm, cnn
    bm.profiling_env()
    opts = bm.launch_env(a.launch_opt)
    log(f"launch_opt={a.launch_opt} ({opts}) ctrlpkt={a.ctrlpkt} defs={os.environ.get('EXTRA_DEFS', '')}")
    out = a.out.resolve()
    out.mkdir(parents=True, exist_ok=True)
    root = Path(ag.__file__).resolve().parents[2]
    os.environ.setdefault("AIEHLC_ROOT", str(root))
    os.environ["AIEGRAPH_PARAMS_INPLACE"] = "1"
    os.environ["AIEGRAPH_WDTYPE"] = "bf16"
    os.environ.setdefault("HOSTCOMPILE_HOST_OPT", "-O2")

    # the model's input and its x86 reference (onnxruntime, fp32)
    shape = (1, 3, 224, 224)
    x = (np.fromfile(a.input, dtype="<f4") if a.input else
         np.random.default_rng(0).standard_normal(shape).astype("<f4")).reshape(shape)
    sess = ort.InferenceSession(str(a.onnx), providers=["CPUExecutionProvider"])
    ref = sess.run(None, {sess.get_inputs()[0].name: x})[0].astype("<f4").reshape(-1)
    inb = out / "input.bin"
    x.tofile(inb)
    hdr = out / "resnet18_inputs.h"
    crc = bm.inputs_header(hdr, "resnet18", [("data", "input", x.reshape(-1))],
                           dict(AIE_MODE="conv,gemm", WDTYPE="bf16"), origin=inb)
    assert crc == "%08x" % zlib.crc32(x.tobytes())
    src = f"input {a.input.name}" if a.input else "seeded N(0,1) input"
    bm.ref_header(out / "p1_ref.h", "resnet18", ref, crc, f"ort/{src}")
    log(f"input {src} crc32={crc}; ORT reference top-1={int(ref.argmax())} ({ref.size} logits)")

    m = ag.load(str(a.onnx.resolve()))
    log(f"loaded {m.name}: {m.input_shapes} -> {m.output_shape}, {sum(m.ops.values())} nodes")
    shutil.rmtree(out / "ag_work", ignore_errors=True)
    emod = m.convert(target="a78", quantize="fp32", image=str(inb), workdir=out / "ag_work", verbose=a.verbose)
    log(f"converted -> {emod.workdir}")
    bm.cross_toolchain(root, log=log)
    res = cnn.offload_all(emod, onnx.load(str(m.onnx_path)), out, warm=a.launch_opt == "warm",
                          ctrlpkt=a.ctrlpkt, verbose=a.verbose, log=log)
    log(f"OFFLOAD resnet18 conv={res['conv'][0]}/{res['conv'][1]} gemm={res['gemm'][0]}/{res['gemm'][1]} "
        f"AIE_MAC_SHARE={res['mac_share']:.1f}%")
    log(f"aie_launches_planned={res['launches']} instances={len(res['shapes'])} kernel={res['kernel']}")
    bm.append_defines(hdr, "resnet18", res["defs"])

    main_c = bm.main_c("resnet18", ["input"], aie=True, runtime_io=True)
    rep = emod.build(target="a78", verbose=a.verbose, main_c=main_c,
                     extra_sources=[bm.cmp_source(), out / "p1_ref.h", hdr],
                     extra_cflags=f"{bm.CMP_CFLAGS} {bm.HEAP_LDFLAG}",
                     runtime_io=[("input", inb)], dump_out=True, launch=a.launch_opt)
    if not rep.ok:
        log(f"build FAILED: {rep.reason}")
        return 1
    for ln in rep.io_info.splitlines():
        log(ln)
    got = cnn.check_driver((Path(rep.elf).parent / "graph_driver.c").read_text(), res)
    log(f"linked driver: {got[0]} aiednn_conv + {got[1]} aiednn_dense call sites")
    elf, wb = out / "main.elf", Path(rep.elf).parent / "weights.bin"
    shutil.copy2(rep.elf, elf)
    if wb.is_file():
        shutil.copy2(wb, out / "weights.bin")
    log(f"built {rep.elf} -> {elf} ({elf.stat().st_size:,} B)")
    return 0


if __name__ == "__main__":
    try:
        rc = main()
    except SystemExit as e:
        rc = e.code if isinstance(e.code, int) else (print(e.code, flush=True) or 1)
    except Exception:
        import traceback
        traceback.print_exc()
        rc = 1
    print(f"GATE_RC={rc}", flush=True)
    sys.exit(rc)
```

Key points:

| Code | What it does |
|---|---|
| `bm.profiling_env()`, `bm.launch_env("warm")` | turn on the board PROF timing and the warm-launch compile macros |
| `bm.inputs_header(...)`, `bm.ref_header(...)` | generate the inputs header (with crc) and the reference-output header used by the board's `CMP` |
| `ag.load(...).convert(target="a78", ...)` | ONNX → TVM C |
| `cnn.offload_all(emod, onnx_model, out, ...)` | match every Conv / Gemm into a group, pick instances, generate the kernel, declare `offload_group`; returns coverage statistics |
| `emod.build(..., runtime_io=[("input", inb)], dump_out=True)` | link main.elf, put the input in the `.aiehlc_io` section, dump the output on the board |
| `cnn.check_driver(...)` | check the call-site count in the linked `graph_driver.c` (20 conv + 1 dense) |

```bash

    --onnx $ONNX --out $WORK/build --input $WORK/img0.bin 2>&1 | tee $WORK/build.log

About 4 minutes (measured: 236 s). The log should contain:

```
[build_resnet18] loaded resnet18_fp32_op17: {'data': [1, 3, 224, 224]} -> [1, 1000], 49 nodes

[build_resnet18] aie_launches_planned=147 instances=10 kernel=.../build/aiek_src/aiek_cnn.cc
[build_resnet18] AIO input input off=128 bytes=602112 crc32=...

`conv=20/20 gemm=1/1 AIE_MAC_SHARE=100.0%` is the AIE coverage: every multiply-accumulate runs on the AIE.

## 5. Run it on the board

The ELF's input lives in the `.aiehlc_io` section, so changing the image needs no rebuild; patch that section with `aiehlc_elfio.py`:

```bash
cd $T
$PY src/tool/elfio/aiehlc_elfio.py patch $WORK/build/main.elf -o $WORK/run0.elf --in input=$WORK/img0.bin --dump-out
$PY script/test/apppaltest.py -board palmyra -host 10.23.224.213 -y --netload \
    --netload-wait 1800 --netload-reply-timeout 600 --netload-max-run-ms 300000 \
    $WORK/run0.elf > $WORK/board0.log 2>&1
grep -v DEBUG $WORK/board0.log | grep -E "graph_run|^LAUNCH warm"
$PY src/tool/elfio/aiehlc_elfio.py readout $WORK/board0.log -o $WORK/board0.npy --ref $WORK/img0_ort.bin
$PY -c "import numpy as np; b=np.load('$WORK/board0.npy').reshape(-1); r=np.fromfile('$WORK/img0_ort.bin','<f4'); \
print('board top-5', np.argsort(-b)[:5].tolist(), 'ort top-5', np.argsort(-r)[:5].tolist())"
```

- `patch` prints `PATCHED crc32=… outside_io_diff=0`: only the input section changed;
- `readout` prints `READOUT … crc_ok=1 cos=… cos_OK=1`: the board's logits match onnxruntime;
- the last line shows whether the top-5 are the same.

**Note:** `apppaltest.py` returns 0 even when the board prints FAIL; check the result lines in the log.

## Troubleshooting

| Symptom | Cause and fix |
|---|---|
| the kernel link reports that DMb does not fit (`no 4096 B area`) | the ports of some "square" instances (Ng == PX) do not fit; `aiegraph.cnn.instance()` already switches to the other launch width automatically |
| some layers with a very small K are wrong on the board (cos only 0.5–0.8) | a known gemm_kacc problem when K ≤ 128; `merge_small_k` already zero-pads these layers onto a large-K instance. For debugging, define the `AIEDNN_SELFCHECK` macro to check every launch on the A78 |
| `[DEBUG]` prints mixed into the result lines | `apppaltest`'s debug output; `grep -v DEBUG` |
