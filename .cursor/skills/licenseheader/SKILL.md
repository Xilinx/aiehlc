# License headers

## The header

C/C++ (`.c .cc .cpp .h .hpp`):

    /******************************************************************************
     * Copyright (C) 2026 Advanced Micro Devices, Inc. All Rights Reserved.
     * SPDX-License-Identifier: Apache-2.0
     ******************************************************************************/

Scripts / config (`.py .sh .toml`, data files a script reads): the same in `#`
lines (`###...###`). Goes **after** a `#!` shebang and a Python `# coding:` line.
Year = the year the file was created. Only for files AMD wrote -- a third-party
file keeps its own notice (CLAUDE.md "Copyright check" rule).

## Finding the candidates

    git ls-files | grep -v '^thirdparty/' | grep -E '\.(c|cc|cpp|h|hpp|py|sh)$' |
      while read f; do head -c 3000 "$f" | grep -qE 'SPDX|Copyright|Licensed under' || echo "$f"; done

The 2026-11-22 sweep found 246; 157 got a header, 89 were left alone on purpose.

## 2026-11-24: every tracked file passes `script/ci/check_opensource.py`

The 93 files the earlier sweep left alone (groups 1-3 below) now carry a header too.
The sections below record *why* they were risky, and how each was handled:

- **Templates (group 1)**: `aiednn._read` (=> `template` / `render` / `runtime_source`) and
  `aiegraph.boardmain._rt` call `aiednn.strip_license()`, which removes ONLY a leading
  `/*** Copyright ... SPDX ... ***/` block. Generated sources are byte-identical
  (sha256 over every template + runtime source, HEAD vs new: equal); `board_main.c`
  has the header ABOVE `/* generated by aiegraph */`, and the generated main.c still
  starts with MARKER. `test_template_is_verbatim` now means "verbatim after the header".
  A new reader of these files must go through `aiednn.template` / `strip_license`.
- **gemm_kernel_port.cc (group 2)**: header added; `kernel_trace_cases.py` stayed 75/75
  (none of its GEMM/TEMPLATE expectations cite a line).
- **Generated / test data (group 3)**: headers added as comments. Two regenerators
  re-add them: `src/mlir/mlirfront{,/mlirlinkrelocate}/gen.sh` (tblgen `.inc`) and
  `conv2dstem/buildtest.sh` (layeriohex copies). `.mlir` test data uses `//` lines --
  `RoutingIR.edit` re-prints through MLIR (drops comments), so it carries a leading
  `//` block over; otherwise `test_edit_is_one_line_and_recorded` sees 4 changed lines.
- `debug/host_cc_tile_topology.py` was a dangling symlink (`./script/...` relative to
  `debug/`) -> `../script/visualization/host_cc_tile_topology.py`.
- Live `file:N` refs into the touched files shifted +4 (14 + 2 by hand for
  `build_unet_cfg.sh`, whose header sits under the shebang).

## Risky groups (historical: why these were left alone)

1. **Text templates read by Python** -- the file's text is spliced into
   generated code, and tests compare that output: everything in
   `src/aiegraph/runtime/`, `src/aiednn/**` (template library, read by
   `aiegraph/cnn.py`, `flashattn.py`, `kincore.py`, `attnsite.py`),
   `example/aiegraph/unet_bk_sdm_tiny/bench/`.
   `script/perf/p0_kacc_host.cc` too: `p0_one_kernel.sh` passes it as `KACC_HOST_FILE`
   (spliced into `kacc_gemm.cc`), hashes it into the build STAMP, and
   `src/costmodel/rst_static.py` cites `p0_kacc_host.cc:169`. `board_main.c`'s **first line
   must be** `/* generated by aiegraph */` (`boardmain.py` `MARKER`) -- a header
   above it breaks the generator. Find them: a candidate's basename quoted in a
   `.py`/`.sh` (`git grep -F '"name.cc"'`), then exclude the false positives that
   are merely *compiled* by the script (`src/mlir/runtime/*.c`, netboot sources).
2. **Sources whose line numbers a test asserts** --
   `src/llvm/convautotile/unitest/kernel_trace_cases.py` expects `case.cc:39`,
   `line 40 in ...` in diagnostics for its base files: `simpleconv2dkernel_port.cc`,
   `simpleconv2dkernel.cc`, `simpleconv2dkernel_space.cc`,
   `simpleconv2dkernel_port_opts.cc` (all `example/tileprogram/ccode/`) and
   `unitest/gemm_kernel_port.cc`; 4 header lines shift every one. Check the
   `*_BASE =` lines there, not a filename glob: a file merely *named* in a test
   is not line-sensitive -- `simpleconv2d_new_load.cc` is read by
   `test_conv_autotile.cpp` / `test_convtune.py` by content (`src.find`,
   `derive`), and took a header with `unitest/run.sh` 170+848, kernel_trace_cases
   74 and convtune all unchanged (2026-11-23). The sweep's "basename quoted in a
   script" filter over-reports; read how each consumer uses the file.
3. **Generated / test data / vendor**: `*/worklocal/*`, `script/test/flowcheck_data/`,
   `debug/routingdangling/`, `codegenexample/aie_control.cpp` (aiecompiler output),
   `conv2d_stem_{in_weight,out_golden}.h` (layeriohex dumps), `*/test/data/`,
   `src/tool/netboot/lwip/` + `test/host/lwip/` (lwIP / Xilinx-derived),
   `resnetengine/fabric/routing.cc` (aiehlc output).
4. **Line-parsed data files** unless the parser skips `#`:
   `resnetengine/eng/kernel_variants` got one only after `build.sh` learned to
   skip comment lines -- before that each header line became a kernel variant.

Group 1 and 2 *can* get a header later, but only with the consumer fixed and its
test re-run (e.g. strip the header when reading the template; regenerate the
expected line numbers).

## `example/` is fully headered (2026-11-23)

Every tracked file under `example/` has a header except the 3 JSON files
(`aiednn/emu_models.json`, `unet_bk_sdm_tiny/partition*.json`): JSON has no
comment syntax, and `emu_models.json` maps every key to a model, so a `_license`
key would become a bogus model. The repo LICENSE covers them.
How the risky ones were done:
- `simpleconv2dkernel{,_port,_port_bf16,_port_opts,_space}.cc`: header added and
  `kernel_trace_cases.py`'s expected `case.cc:N` / `line N` moved +4 in exactly
  the cases that failed (10). Procedure: add the header, run the cases, shift
  only the FAILing cases' strings, re-run to 74/74.
- `unet_bk_sdm_tiny/bench/*` templates: `_bench` / `render` fill `@NAME@` and
  splice the text into a larger source; a comment carries no `@NAME@`, so the
  header just rides along into the generated file.
- `a78_layer_cflags.txt`: `aiegraph.boardmain.read_cflags_file` joined EVERY
  word into CFLAGS; it now skips `#` lines (tests in
  `test_arm_build_layer_cflags.py`). Any other line-parsed data file needs the
  same check before it gets a header.
- Syntax per type: `.md` / `.prx` `<!-- ... -->` (repo convention, see
  `doc/llvm_mlir_pitfalls.md`), `.bcf` `//` (`src/sim/stub_kernel.bcf`),
  `.txt` / `.log` `#`.

## Tutorial listings

`tutorial/aieprogram/sync_code.py` embeds whole example files into the tutorials
and the root `README.md`. `drop_license()` removes the Copyright / SPDX lines of
the file's **first** comment block (the whole block if only decoration remains,
otherwise the description stays). After adding headers to examples, run
`python3 tutorial/aieprogram/sync_code.py` then `--check`; the listings must not
change.

## Doc line references (`file:N`) shift by 4

A header moves every line down 4, so a doc's `` `file.py:N` `` now points 4 lines
early. Grep all tracked `*.md` for `name.ext:N[-M]` into the touched files, then:
- **pinned refs -- leave**: `tutorial/aieprogram/07_special_data_flow/*.md` cite
  `<!-- ref PATH:L TOKEN -->` against a fixed base (`script/check_refs.sh`,
  `BASE_REV=43fcb8f`); shifting them breaks `check_refs`. Run it on each file.
- **dated plans -- leave**: `docs/plans/2026-*` are snapshots.
- **live refs -- shift**, only when the basename resolves to exactly one touched
  file and the old line N equals the new line N+4 (the 2026-11-23 sweep shifted
  11 in `doc/design/tvm_custom_model_recipe.md`; `__init__.py:52` there names a
  `run_resnet` that no longer exists -- stale before, left alone).
