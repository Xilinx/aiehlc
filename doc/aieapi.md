# XAie API Guide

This guide introduces the XAie driver API for AMD Versal AI Engine applications. References:
- `example/perf/aieml_perf.cc` — single-tile, high-level routing API (simple)
- `example/debug/aieml_controlperf.cc` — host-side control-plane microbenchmark: times each `__Runtime_*` / XAie config API (bd_config, startio, wait_io, load/launch kernel group) to quantify how much wall time the host spends issuing AXI-MM register writes per matmul iteration
- `src/mlir/mlirfront/tilinglinalg/pass/routingimplement/codegenexample/aie_control.cpp` — multi-tile graph with manual stream switch, DMA BDs, locks, and packet routing (advanced, generated by aiecompiler)
- `../../aiebr/aiebaremetal2/src/common_layer/` — higher-level runtime layer wrapping XAie APIs with graph/GMIO/DMA/lock abstractions

Source: `thirdparty/alib/aie-rt/driver/src`.

## Include and Basics

```c
#include "xaiengine.h"    // umbrella header - pulls in all XAie APIs
#include "xil_cache.h"    // cache control (baremetal)
```

**Core types:**

| Type | Definition |
|------|-----------|
| `XAie_LocType` | `{ u8 Row, Col }` — tile location |
| `XAie_DevInst` | Device instance — holds partition geometry, IO backend, state |
| `XAie_MemInst` | Allocated memory handle — VAddr, DevAddr, Size, Cache |
| `XAie_RoutingInstance` | Routing handler — manages routes and core constraints |
| `XAie_DmaDesc` | DMA buffer descriptor |
| `XAie_Lock` | `{ u16 LockId, s8 LockVal }` |
| `AieRC` | Return code enum: `XAIE_OK`, `XAIE_ERR`, `XAIE_INVALID_TILE`, etc. |

**Tile location helper:**

```c
XAie_LocType loc = XAie_TileLoc(col, row);  // note: (col, row) order
```

## Step 1: Device Setup

```c
// Define device geometry (differs by AIE generation)
XAie_SetupConfig(ConfigPtr, HW_GEN, XAIE_BASE_ADDR,
    XAIE_COL_SHIFT, XAIE_ROW_SHIFT,
    XAIE_NUM_COLS, XAIE_NUM_ROWS, XAIE_SHIM_ROW,
    XAIE_RES_TILE_ROW_START, XAIE_RES_TILE_NUM_ROWS,
    XAIE_AIE_TILE_ROW_START, XAIE_AIE_TILE_NUM_ROWS);

// Declare device instance
XAie_InstDeclare(DevInst, &ConfigPtr);

// Initialize driver
AieRC RC = XAie_CfgInitialize(&DevInst, &ConfigPtr);

// Select IO backend
XAie_SetIOBackend(&DevInst, XAIE_IO_BACKEND_BAREMETAL);
```

**Backends:** `XAIE_IO_BACKEND_BAREMETAL`, `XAIE_IO_BACKEND_LINUX`, `XAIE_IO_BACKEND_METAL`, `XAIE_IO_BACKEND_SIM`, `XAIE_IO_BACKEND_SOCKET`.

**Generations:** `XAIE_DEV_GEN_AIEML` (AIE2), `XAIE_DEV_GEN_AIE2PS` (AIE2PS/AIE5).

**AIE2+ NPI address update** (baremetal only):

```c
XAie_UpdateNpiAddr(&DevInst, 0xF6D10000);   // AIE2
XAie_UpdateNpiAddr(&DevInst, 0xf6d50000);   // AIE2PS
```

## Step 2: Partition Init

```c
// AIE2+: initialize partition (resets tiles, clocks, isolation)
XAie_PartitionInitialize(&DevInst, NULL);  // NULL = default options

// AIE1: request tiles instead
XAie_PmRequestTiles(&DevInst, NULL, 0);    // NULL,0 = request all tiles
```

**Partition init options** (combine with `|`):
`XAIE_PART_INIT_OPT_COLUMN_RST`, `XAIE_PART_INIT_OPT_SHIM_RST`, `XAIE_PART_INIT_OPT_ZEROIZEMEM`, `XAIE_PART_INIT_OPT_DEFAULT`.

## Step 3: Core Load and Run

```c
XAie_LocType tile = XAie_TileLoc(4, 4);

// Reset → unreset → load ELF → (routing setup) → run
XAie_CoreReset(&DevInst, tile);
XAie_CoreUnreset(&DevInst, tile);
XAie_LoadElfMem(&DevInst, tile, (unsigned char *)kernel_func);  // from memory
// or: XAie_LoadElf(&DevInst, tile, "/path/to/kernel.elf", 0);  // from file

// Wait for core to finish
XAie_CoreWaitForDone(&DevInst, tile, 0);  // 0 = no timeout
```

`XAie_LoadElfMem` loads from a memory buffer (used when kernel ELF is embedded in host via `ld -r -b binary`). `XAie_LoadElf` loads from a file path.

## Step 4: Routing

The routing API automatically finds and configures stream switch paths between tiles.

```c
XAie_RoutingInstance *routingInst = XAie_InitRoutingHandler(&DevInst);

// Create route: shim tile (col,0) ↔ compute tile (4,4)
XAie_Route(routingInst, NULL, XAie_TileLoc(shimcol, 0), XAie_TileLoc(4, 4));  // in
XAie_Route(routingInst, NULL, XAie_TileLoc(4, 4), XAie_TileLoc(shimcol, 0));  // out

// Enable cores associated with routing
XAie_Run(routingInst, 1);  // 1 iteration
```

**Manual stream switch** (alternative to XAie_Route — used in `aie_control.cpp`):

```c
// Circuit-switched connection: slave port → master port on a tile
XAie_StrmConnCctEnable(&DevInst, XAie_TileLoc(col, row),
    SOUTH, 0,   // slave: direction, port index
    NORTH, 0);  // master: direction, port index
```

Port types: `CORE`, `DMA`, `CTRL`, `FIFO`, `SOUTH`, `WEST`, `NORTH`, `EAST`, `TRACE`.

**Multi-hop routing example** (from `aie_control.cpp` — shim col2 → memtile → compute tiles col0):

```c
// Shim tile: external DDR stream → north into memtile chain
XAie_StrmConnCctEnable(&DevInst, XAie_TileLoc(2, 0), SOUTH, 3, NORTH, 4);
// MemTile row 1: pass through north
XAie_StrmConnCctEnable(&DevInst, XAie_TileLoc(2, 1), SOUTH, 4, NORTH, 4);
// MemTile row 2: receive into DMA for buffering
XAie_StrmConnCctEnable(&DevInst, XAie_TileLoc(2, 2), SOUTH, 4, DMA, 0);
// MemTile DMA output → north toward compute tiles
XAie_StrmConnCctEnable(&DevInst, XAie_TileLoc(2, 2), DMA, 0, NORTH, 4);
// Compute tile: fan-out — receive from south + forward north + deliver to local DMA
XAie_StrmConnCctEnable(&DevInst, XAie_TileLoc(0, 4), SOUTH, 4, NORTH, 4);
XAie_StrmConnCctEnable(&DevInst, XAie_TileLoc(0, 4), SOUTH, 4, DMA, 0);
```

**Packet-switched routing** (multiple streams share one physical path, demuxed by packet ID):

```c
// Enable slave port for packet switching
XAie_StrmPktSwSlavePortEnable(&DevInst, XAie_TileLoc(0, 4), DMA, 0);

// Configure slave slot: match packet ID, route to arbiter/msel
XAie_StrmPktSwSlaveSlotEnable(&DevInst, XAie_TileLoc(0, 4),
    DMA, 0,            // slave port type, port number
    0,                 // slot number
    {.PktId=0, .PktType=0},  // packet to match
    0x1f,              // mask (0x1f = match all 5 bits of PktId)
    0,                 // msel (master select)
    0);                // arbiter

// Enable master port for packet switching
XAie_StrmPktSwMstrPortEnable(&DevInst, XAie_TileLoc(0, 4),
    SOUTH, 3,                     // master port type, port number
    XAIE_SS_PKT_DROP_HEADER,      // or XAIE_SS_PKT_DONOT_DROP_HEADER
    0,                             // arbiter
    0x1);                          // msel enable mask
```

**Shim DMA stream ports:**

```c
XAie_EnableShimDmaToAieStrmPort(&DevInst, XAie_TileLoc(col, 0), portNum);  // DDR→AIE
XAie_EnableAieToShimDmaStrmPort(&DevInst, XAie_TileLoc(col, 0), portNum);  // AIE→DDR
```

## Step 5: Memory Allocation

```c
u32 size = 512 * sizeof(u32);

// Allocate DMA-capable memory
XAie_MemInst *in  = XAie_MemAllocate(&DevInst, size, XAIE_MEM_CACHEABLE);
XAie_MemInst *out = XAie_MemAllocate(&DevInst, size, XAIE_MEM_CACHEABLE);

// Get addresses
u64 phy_in  = XAie_MemGetDevAddr(in);   // physical/device address (for DMA)
void *virt  = XAie_MemGetVAddr(in);     // virtual address (for CPU)

// Fill data (use physical addr directly on baremetal, virtual on Linux)
for (int i = 0; i < 512; i++)
    ((int32_t *)phy_in)[i] = i + 1;
```

Cache types: `XAIE_MEM_CACHEABLE`, `XAIE_MEM_NONCACHEABLE`.

## Step 6: Data Movement

**High-level (with routing):**

```c
// CPU cache → device
XAie_MemSyncForDev(in);

// DDR → AIE tile data memory
XAie_MoveDataExternal2Aie(routingInst,
    XAie_TileLoc(shimcol, 0),  // source shim tile
    in,                         // source memory handle
    size,                       // data size in bytes
    0x1000,                     // destination tile memory address
    XAie_TileLoc(4, 4));       // destination compute tile

// AIE tile data memory → DDR
XAie_MoveDataAie2External(routingInst,
    XAie_TileLoc(4, 4),        // source compute tile
    0x6000,                     // source tile memory address
    size,                       // data size in bytes
    out,                        // destination memory handle
    XAie_TileLoc(shimcol, 0)); // destination shim tile

// Device → CPU cache
XAie_MemSyncForCPU(out);
```

**Low-level DMA (manual BD config):**

```c
XAie_DmaDesc desc;
XAie_DmaDescInit(&DevInst, &desc, XAie_TileLoc(col, row));
XAie_DmaSetAddrLen(&desc, addr, length);
XAie_DmaEnableBd(&desc);
XAie_DmaWriteBd(&DevInst, &desc, XAie_TileLoc(col, row), bdNum);
XAie_DmaChannelPushBdToQueue(&DevInst, XAie_TileLoc(col, row), chNum, DMA_S2MM, bdNum);
XAie_DmaChannelEnable(&DevInst, XAie_TileLoc(col, row), chNum, DMA_S2MM);
XAie_DmaWaitForDone(&DevInst, XAie_TileLoc(col, row), chNum, DMA_S2MM, timeoutUs);
```

DMA directions: `DMA_S2MM` (stream-to-memory), `DMA_MM2S` (memory-to-stream).

**DMA with locks and BD chaining** (ping-pong double buffering — from `aie_control.cpp`):

```c
// Set initial lock value (2 = both buffers available for write)
XAie_LockSetValue(&DevInst, XAie_TileLoc(0, 4), XAie_LockInit(0, 2));

// BD 0: first ping buffer
XAie_DmaDesc DmaInst;
XAie_DmaDescInit(&DevInst, &DmaInst, XAie_TileLoc(0, 4));
XAie_DmaSetAddrLen(&DmaInst, 0xfb40, 588);
XAie_DmaSetLock(&DmaInst,
    XAie_LockInit(0, -1),   // acquire: lock 0, decrement by 1
    XAie_LockInit(1, 1));   // release: lock 1, increment by 1
XAie_DmaSetNextBd(&DmaInst, 1, XAIE_ENABLE);  // chain to BD 1
XAie_DmaEnableBd(&DmaInst);
XAie_DmaWriteBd(&DevInst, &DmaInst, XAie_TileLoc(0, 4), 0);

// BD 1: second pong buffer (chains back to BD 0)
XAie_DmaDescInit(&DevInst, &DmaInst, XAie_TileLoc(0, 4));
XAie_DmaSetAddrLen(&DmaInst, 0x4000, 588);
XAie_DmaSetLock(&DmaInst, XAie_LockInit(0, -1), XAie_LockInit(1, 1));
XAie_DmaSetNextBd(&DmaInst, 0, XAIE_ENABLE);  // chain back to BD 0
XAie_DmaEnableBd(&DmaInst);
XAie_DmaWriteBd(&DevInst, &DmaInst, XAie_TileLoc(0, 4), 1);

// Start the DMA channel queue
XAie_DmaChannelSetStartQueue(&DevInst, XAie_TileLoc(0, 4),
    0,          // channel number
    DMA_S2MM,   // direction
    0,          // starting BD number
    1,          // repeat count
    XAIE_DISABLE);  // enable token
```

**DMA with packet headers** (for packet-switched output):

```c
XAie_DmaDescInit(&DevInst, &DmaInst, XAie_TileLoc(0, 4));
XAie_DmaSetAddrLen(&DmaInst, 0x0, 32);
XAie_DmaSetLock(&DmaInst, XAie_LockInit(7, -1), XAie_LockInit(6, 1));
XAie_DmaSetPkt(&DmaInst, {.PktId=0, .PktType=0});  // attach packet header
XAie_DmaSetNextBd(&DmaInst, 5, XAIE_ENABLE);
XAie_DmaEnableBd(&DmaInst);
XAie_DmaWriteBd(&DevInst, &DmaInst, XAie_TileLoc(0, 4), 4);
```

**Multi-dimensional DMA** (strided transfers on MemTiles):

```c
// Define dimension descriptors: {stride, size} pairs
XAie_DmaDimDesc dims[4] = {
    {.AieMlDimDesc = {1, 7}},      // dim 0: stride=1, wrap=7
    {.AieMlDimDesc = {230, 7}},    // dim 1: stride=230, wrap=7
    {.AieMlDimDesc = {2530, 3}},   // dim 2: stride=2530, wrap=3
    {.AieMlDimDesc = {2, 0}},      // dim 3: stride=2, wrap=0
};
XAie_DmaTensor tensor = {4, dims};  // {num_dims, dim_descs}

XAie_DmaDescInit(&DevInst, &DmaInst, XAie_TileLoc(2, 2));
XAie_DmaSetMultiDimAddr(&DmaInst, &tensor, 524288, 65856);  // base_addr, total_len
XAie_DmaSetLock(&DmaInst, XAie_LockInit(64, 1), XAie_LockInit(65, 1));
XAie_DmaEnableBd(&DmaInst);
XAie_DmaWriteBd(&DevInst, &DmaInst, XAie_TileLoc(2, 2), bdNum);
```

**Direct tile memory access** (debug/validation):

```c
u32 data[512];
XAie_DataMemBlockRead(&DevInst, XAie_TileLoc(4,4), 0x1000, data, sizeof(data));
XAie_DataMemBlockWrite(&DevInst, XAie_TileLoc(4,4), 0x1000, data, sizeof(data));
```

## Step 7: Locks (Tile Synchronization)

```c
XAie_Lock lock = XAie_LockInit(lockId, value);

XAie_LockAcquire(&DevInst, tile, lock, timeout);  // block until acquired
XAie_LockRelease(&DevInst, tile, lock, timeout);
XAie_LockSetValue(&DevInst, tile, lock);           // set without acquire
```

## Step 8: Teardown

```c
XAie_PartitionTeardown(&DevInst);
// Optionally: XAie_MemFree(in); XAie_MemFree(out);
// Optionally: XAieRoutingInstance_free(routingInst);
```

## Complete Flow: Simple (from aieml_perf.cc)

Single tile, high-level routing API:

```
1. XAie_SetupConfig         — define device geometry
2. XAie_InstDeclare         — declare device instance
3. XAie_CfgInitialize       — init driver
4. XAie_SetIOBackend        — select backend (baremetal/linux)
5. XAie_UpdateNpiAddr       — NPI address (AIE2+ baremetal)
6. XAie_PartitionInitialize — init partition
7. XAie_CoreReset/Unreset   — prepare compute tile
8. XAie_LoadElfMem          — load kernel into tile
9. XAie_InitRoutingHandler  — create routing instance
10. XAie_Route (x2)         — setup bidirectional routes
11. XAie_MemAllocate (x2)   — allocate input/output DDR buffers
12. XAie_MemSyncForDev      — flush input to device
13. XAie_MoveDataExternal2Aie — DDR → tile memory
14. XAie_Run                — start kernel core
15. XAie_CoreWaitForDone    — wait for kernel completion
16. XAie_MoveDataAie2External — tile memory → DDR
17. XAie_MemSyncForCPU      — invalidate cache for output
18. XAie_PartitionTeardown  — cleanup
```

## Complete Flow: Advanced Multi-Tile (from aie_control.cpp)

Multi-tile graph with manual routing, DMA BDs, locks, and packet switching:

```
1. XAie_SetupConfig / XAie_CfgInitialize   — device setup
2. XAie_PmRequestTiles (specific tiles)     — request only used tiles
3. XAie_PartitionInitialize                 — reset partition
4. XAie_StrmConnCctEnable (many)            — circuit-switched routes across tiles
5. XAie_StrmPktSwSlavePortEnable            — enable packet-switch slave ports
6. XAie_StrmPktSwSlaveSlotEnable            — configure packet ID matching per slot
7. XAie_StrmPktSwMstrPortEnable             — enable packet-switch master ports
8. XAie_EnableShimDmaToAieStrmPort          — connect shim DMA to stream
9. XAie_EnableAieToShimDmaStrmPort          — connect stream to shim DMA
10. XAie_CoreReset / XAie_CoreUnreset (x4)  — reset all compute cores
11. XAie_LoadElf (x4)                       — load kernel ELFs from files
12. XAie_LockSetValue (many)                — initialize lock semaphores
13. XAie_DmaDescInit + SetAddrLen + SetLock
    + SetNextBd + EnableBd + WriteBd (many) — configure ping-pong BD chains
14. XAie_DmaSetPkt (output BDs)             — attach packet headers
15. XAie_DmaSetMultiDimAddr (MemTile BDs)   — strided multi-dim transfers
16. XAie_DmaChannelSetStartQueue            — start DMA channel queues
17. XAie_CoreEnable (x4)                    — enable all compute cores
```

Key differences from simple flow:
- **No XAie_Route**: all stream switch connections are manually configured hop-by-hop
- **Ping-pong DMA**: BD 0 → BD 1 → BD 0 chains with lock-based synchronization
- **Packet routing**: multiple outputs share one physical stream, demuxed by packet ID
- **MemTile buffering**: DDR → shim DMA → MemTile DMA (with multi-dim reshape) → compute tiles
- **Per-tile locks**: producer/consumer lock pairs coordinate DMA and compute

## XAie Patterns from Runtime (common_layer)

Source: `../../aiebr/aiebaremetal2/src/common_layer/aeg_runtime_api.cpp`

This file demonstrates real-world XAie call patterns for core control, DMA, locks, and data memory access. The patterns below are extracted directly from this production runtime.

### Transaction Batching

Batch multiple XAie calls into a single transaction for efficiency:

```c
XAie_StartTransaction(&DevInst, XAIE_TRANSACTION_ENABLE_AUTO_FLUSH);
for (int i = 0; i < numCores; i++)
    XAie_CoreEnable(&DevInst, coreTiles[i]);
XAie_SubmitTransaction(&DevInst, nullptr);
```

### Core Enable with Broadcast Event

Synchronize startup of many cores using broadcast events instead of enabling one-by-one:

```c
// Configure all cores to wait for broadcast event 7
XAie_StartTransaction(&DevInst, XAIE_TRANSACTION_ENABLE_AUTO_FLUSH);
for (int i = 0; i < numCores; i++) {
    XAie_ClearCoreDisableEventOccurred(&DevInst, coreTiles[i]);
    XAie_CoreConfigureEnableEvent(&DevInst, coreTiles[i], XAIE_EVENT_BROADCAST_7_CORE);
}
XAie_SubmitTransaction(&DevInst, nullptr);

// Trigger the broadcast from shim tile — all cores start simultaneously
XAie_EventGenerate(&DevInst, XAie_TileLoc(0, 0), XAIE_PL_MOD, XAIE_EVENT_BROADCAST_A_8_PL);

// Wait ~150 cycles, then reset enable event back to none
XAie_StartTransaction(&DevInst, XAIE_TRANSACTION_ENABLE_AUTO_FLUSH);
for (int i = 0; i < numCores; i++)
    XAie_CoreConfigureEnableEvent(&DevInst, coreTiles[i], XAIE_EVENT_NONE_CORE);
XAie_SubmitTransaction(&DevInst, nullptr);
```

### Core Wait with Retry Loop

`XAie_CoreWaitForDone` has a short internal timeout; production code retries in a loop:

```c
// Retry until done (timeout=0 means driver's default short timeout)
while (XAie_CoreWaitForDone(&DevInst, tile, 0) == XAIE_CORE_STATUS_TIMEOUT) {}
XAie_CoreDisable(&DevInst, tile);
```

### Writing Iteration Count to Tile Memory

Set iteration count before enabling a core (core reads it from its data memory):

```c
XAie_DataMemWrWord(&DevInst, iterMemTile, iterMemAddr, (u32)iterations);
XAie_CoreEnable(&DevInst, coreTile);
```

### Timer and Cycle-Accurate Wait

```c
u64 startTime, currentTime;
XAie_ReadTimer(&DevInst, tile, XAIE_CORE_MOD, &startTime);
// ... do work ...
XAie_ReadTimer(&DevInst, tile, XAIE_CORE_MOD, &currentTime);
u64 elapsed = currentTime - startTime;

// Or wait a specific number of cycles:
XAie_WaitCycles(&DevInst, tile, XAIE_CORE_MOD, cyclesToWait);
```

### Ping-Pong RTP Update via Locks + Data Memory

Read selector, write to alternate buffer, flip selector — with lock synchronization:

```c
// Acquire selector lock
XAie_LockAcquire(&DevInst, selectorTile, XAie_LockInit(selectorLockId, acqVal), LOCK_TIMEOUT);

// Read current selector (0=ping, 1=pong), flip it
u32 selector;
XAie_DataMemRdWord(&DevInst, selectorTile, selectorAddr, &selector);
selector = 1 - selector;

// Acquire the target buffer lock, write data
if (selector == 1) {  // write to pong
    XAie_LockAcquire(&DevInst, pongTile, XAie_LockInit(pongLockId, acqVal), LOCK_TIMEOUT);
    XAie_DataMemBlockWrite(&DevInst, pongTile, pongAddr, pValue, numBytes);
} else {  // write to ping
    XAie_LockAcquire(&DevInst, pingTile, XAie_LockInit(pingLockId, acqVal), LOCK_TIMEOUT);
    XAie_DataMemBlockWrite(&DevInst, pingTile, pingAddr, pValue, numBytes);
}

// Update selector, release locks
XAie_DataMemWrWord(&DevInst, selectorTile, selectorAddr, selector);
XAie_LockRelease(&DevInst, selectorTile, XAie_LockInit(selectorLockId, relVal), LOCK_TIMEOUT);
XAie_LockRelease(&DevInst, bufTile, XAie_LockInit(bufLockId, relVal), LOCK_TIMEOUT);
```

### Shared Buffer Update with Producer/Consumer Locks

```c
// Acquire producer lock (prevent reads)
XAie_LockAcquire(&DevInst, tile, XAie_LockInit(producerLockId, -1), LOCK_TIMEOUT);
// Acquire consumer lock (wait for all readers done)
XAie_LockAcquire(&DevInst, tile, XAie_LockInit(consumerLockId, -numOutputs), LOCK_TIMEOUT);
// Write data
XAie_DataMemBlockWrite(&DevInst, tile, addr, pValue, numBytes);
// Release both locks
XAie_LockRelease(&DevInst, tile, XAie_LockInit(producerLockId, 1), LOCK_TIMEOUT);
XAie_LockRelease(&DevInst, tile, XAie_LockInit(consumerLockId, numOutputs), LOCK_TIMEOUT);
```

### GMIO: Shim DMA with BD Recycling

Configure shim DMA channel, enqueue BDs, recycle completed ones:

```c
XAie_LocType shimTile = XAie_TileLoc(shimCol, 0);
XAie_DmaDesc shimDmaInst;
XAie_DmaDescInit(&DevInst, &shimDmaInst, shimTile);

// Enable channel first
XAie_DmaChannelEnable(&DevInst, shimTile, physicalCh, DMA_MM2S);

// Set AXI burst length (once per GMIO)
XAie_DmaSetAxi(&shimDmaInst, 0, burstLength, 0, 0, 0);

// Enqueue a BD
XAie_DmaSetAddrLen(&shimDmaInst, physAddr, size);
XAie_DmaSetLock(&shimDmaInst, XAie_LockInit(bdNum, 0), XAie_LockInit(bdNum, 0));  // AIEML
XAie_DmaEnableBd(&shimDmaInst);
XAie_DmaWriteBd(&DevInst, &shimDmaInst, shimTile, bdNum);
XAie_DmaChannelPushBdToQueue(&DevInst, shimTile, physicalCh, DMA_MM2S, bdNum);

// Poll for completed BDs to recycle
u8 numPending = 0;
XAie_DmaGetPendingBdCount(&DevInst, shimTile, physicalCh, DMA_MM2S, &numPending);
int numCompleted = maxQueueSize - numPending;  // recycle these BDs

// Wait for channel done
while (XAie_DmaWaitForDone(&DevInst, shimTile, physicalCh, DMA_MM2S, 0) != XAIE_OK) {}
```

### Advanced DMA BD Configuration

Full BD setup with multi-dim addressing, zero padding, packet ID, compression, iteration, and chaining:

```c
XAie_LocType tileLoc = XAie_TileLoc(col, row);
XAie_DmaDesc dmaInst;
XAie_DmaDescInit(&DevInst, &dmaInst, tileLoc);

// Multi-dimensional addressing (strides + wraps)
XAie_DmaDimDesc dimDescs[] = {
    {.AieMlDimDesc = {stepsize0, wrap0}},
    {.AieMlDimDesc = {stepsize1, wrap1}},
};
XAie_DmaTensor dims = {2, dimDescs};
XAie_DmaSetMultiDimAddr(&dmaInst, &dims, address, length);

// Zero padding per dimension
XAie_DmaSetZeroPadding(&dmaInst, 0, DMA_ZERO_PADDING_BEFORE, padBefore);
XAie_DmaSetZeroPadding(&dmaInst, 0, DMA_ZERO_PADDING_AFTER, padAfter);

// Packet ID (for packet-switched streams)
XAie_DmaSetPkt(&dmaInst, {.PktId = packetId, .PktType = 0});
XAie_DmaSetOutofOrderBdId(&dmaInst, oobdId);

// Suppress TLAST
XAie_DmaTlastDisable(&dmaInst);

// BD iteration (for repeat patterns)
XAie_DmaSetBdIteration(&dmaInst, iterStepsize, iterWrap, iterCurrent);

// Compression
XAie_DmaEnableCompression(&dmaInst);

// Lock acquire/release
XAie_DmaSetLock(&dmaInst, XAie_LockInit(acqId, acqVal), XAie_LockInit(relId, relVal));

// AXI burst (shim tiles only)
XAie_DmaSetAxi(&dmaInst, 0, burstLen, 0, 0, 0);

// BD chaining
XAie_DmaSetNextBd(&dmaInst, nextBdId, XAIE_ENABLE);

// Finalize: enable, write, start queue
XAie_DmaEnableBd(&dmaInst);
XAie_DmaWriteBd(&DevInst, &dmaInst, tileLoc, bdId);
XAie_DmaChannelSetStartQueue(&DevInst, tileLoc, channel, dir, startBdId, repeatCount, enableToken);
```

### Runtime BD Address Update

Change a BD's address without reconfiguring the whole descriptor:

```c
XAie_DmaUpdateBdAddr(&DevInst, tileLoc, newAddress, bdId);
```

### AIE1 vs AIEML Lock Semantics

Lock acquire/release values differ between generations:

```c
u8 devGen = DevInst.DevProp.DevGen;

if (devGen >= XAIE_DEV_GEN_AIEML) {
    // AIEML: semaphore-style, acquire with negative value (decrement)
    XAie_LockAcquire(&DevInst, tile, XAie_LockInit(lockId, -1), timeout);   // acquire
    XAie_LockRelease(&DevInst, tile, XAie_LockInit(lockId, 1), timeout);    // release
    // Async RTP first-time: acquire with 0
    XAie_LockAcquire(&DevInst, tile, XAie_LockInit(lockId, 0), timeout);
} else {
    // AIE1: binary lock, acquire with XAIE_LOCK_WITH_NO_VALUE or 0/1
    XAie_LockAcquire(&DevInst, tile, XAie_LockInit(lockId, XAIE_LOCK_WITH_NO_VALUE), timeout);
    XAie_LockRelease(&DevInst, tile, XAie_LockInit(lockId, 1), timeout);
}
```
